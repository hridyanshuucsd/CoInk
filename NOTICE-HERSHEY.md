# Hershey stroke data notice

`public/hershey-glyphs.js` contains a converted subset of the Hershey Script
Medium vector font data distributed with Inkscape. The data is converted to a
compact JavaScript stroke representation; no font file is bundled.

The source font states the following required acknowledgements:

- The Hershey Fonts were originally created by Dr. A. V. Hershey while working
  at the U. S. National Bureau of Standards.
- The format of the font data in that distribution was originally created by
  James Hurt, Cognition, Inc., 900 Technology Park Drive, Billerica, MA 01821.

The source distribution permits use for any purpose, commercial or otherwise,
provided those acknowledgements accompany the font data and the data is not
converted to the restricted U.S. NTIS eight-byte point format.

The SVG adaptation used to generate this JavaScript data was prepared by
Windell H. Oskay / Evil Mad Scientist Laboratories and traces through the
Hershey SVG work by Marty McGuire.
